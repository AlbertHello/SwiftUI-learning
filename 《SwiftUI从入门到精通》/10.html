第10章：绘图与形状

Path、Shape协议、内置形状与自定义绘图

本章概述

在SwiftUI中，绘图是构建自定义UI和视觉效果的基石。本章将深入探讨SwiftUI的绘图系统，从基础的Path和Shape协议，到便捷的内置形状，最后引导你创建属于自己的自定义形状。掌握这些知识，你将能绘制出任何你能想象的界面元素。

1. 核心概念：Path

Path是SwiftUI中描述二维形状轮廓的基本结构。你可以把它想象为一支虚拟的画笔，通过一系列指令（如移动、画线、画弧）来“描绘”形状。

import SwiftUI

struct PathExampleView: View {
    var body: some View {
        Path { path in
            // 将画笔移动到起点 (50, 20)
            path.move(to: CGPoint(x: 50, y: 20))
            // 画一条线到 (200, 20)
            path.addLine(to: CGPoint(x: 200, y: 20))
            // 画一条线到 (125, 150)
            path.addLine(to: CGPoint(x: 125, y: 150))
            // 闭合路径，画一条线回起点
            path.closeSubpath()
        }
        .fill(Color.blue) // 填充颜色
        .stroke(Color.orange, lineWidth: 5) // 描边
        .frame(width: 250, height: 200)
    }
}

2. Shape协议

Shape是一个协议，任何符合该协议的类型都能定义为一个可被SwiftUI视图系统识别和渲染的形状。它要求实现一个关键方法：path(in rect: CGRect) -> Path。

3. 内置形状 (Built-in Shapes)

SwiftUI贴心地提供了一系列开箱即用的基本形状，它们都符合Shape协议，可以直接使用。

形状 说明 示例代码 预览
Circle 圆形 Circle().fill(.red)
Rectangle 矩形 Rectangle().fill(.blue)
RoundedRectangle 圆角矩形 RoundedRectangle(cornerRadius: 10)
Capsule 胶囊形状 Capsule().fill(.orange)
Ellipse 椭圆 Ellipse().fill(.purple)

提示： 内置形状不仅可以直接填充(.fill())，还可以添加描边(.stroke())、阴影(.shadow())、裁剪(.clipShape())等修饰符，功能非常强大。

5. 关键知识点总结

  1. Path是基础： 所有形状最终都通过Path来定义轮廓。掌握move(to:), addLine(to:), addCurve(to:control1:control2:), addArc(...)等方法是关键。
  2. Shape协议是桥梁： 它让自定义的路径逻辑能够无缝集成到SwiftUI的视图体系中，享受所有视图修饰符。
  3. 内置形状高效便捷： 对于常见图形，直接使用Circle, Rectangle等，省时省力。
  4. 组合与修饰： 形状可以像普通视图一样使用.fill(), .stroke(), .rotationEffect(), .scaleEffect()等修饰符，创造出复杂效果。
  5. 动画支持： 由于Shape符合Animatable协议，通过改变其参数（如圆角半径、控制点），可以轻松实现平滑的形状变形动画。
