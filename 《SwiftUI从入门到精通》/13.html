第13章：手势识别 - 让应用“触”手可及

本章将深入探讨SwiftUI中强大的手势识别系统，学习如何通过TapGesture、LongPressGesture、DragGesture、MagnificationGesture、RotationGesture等手势，为应用添加直观、自然的交互体验。

📱 手势识别概述

在SwiftUI中，手势是用户与应用程序交互的核心方式之一。SwiftUI提供了一套声明式的手势API，使得添加手势识别变得简单而直观。所有手势都通过.gesture()修饰符附加到视图上。

SwiftUI手势架构图

💡 核心概念

SwiftUI手势系统基于值类型和修饰符。每个手势都会产生一个值（如拖拽的距离、缩放的比例等），你可以通过闭包或绑定来响应这些值的变化。

👆 基础手势详解

TapGesture（点击手势）

最基本的交互手势，用于检测轻点操作。

  • count: 点击次数（默认为1）
  • onEnded: 手势完成时的回调
  • 支持单点、双击、多点点击
struct TapExampleView: View {
    @State private var tapped = false
    
    var body: some View {
        Circle()
            .fill(tapped ? Color.blue : Color.green)
            .frame(width: 100, height: 100)
            .gesture(
                TapGesture(count: 1)
                    .onEnded {
                        withAnimation {
                            tapped.toggle()
                        }
                    }
            )
    }
}

LongPressGesture（长按手势）

检测长时间按压操作，常用于显示上下文菜单。

  • minimumDuration: 最小持续时间
  • maximumDistance: 最大允许移动距离
  • 支持按压开始、结束、取消事件
struct LongPressExampleView: View {
    @State private var isPressed = false
    
    var body: some View {
        RoundedRectangle(cornerRadius: 15)
            .fill(isPressed ? Color.orange : Color.purple)
            .frame(width: 150, height: 80)
            .scaleEffect(isPressed ? 0.9 : 1.0)
            .gesture(
                LongPressGesture(minimumDuration: 0.5)
                    .onChanged { _ in
                        withAnimation {
                            isPressed = true
                        }
                    }
                    .onEnded { _ in
                        withAnimation {
                            isPressed = false
                        }
                        // 显示菜单或执行操作
                    }
            )
    }
}

DragGesture（拖拽手势）

检测拖拽操作，提供丰富的拖拽数据。

  • minimumDistance: 触发拖拽的最小距离
  • coordinateSpace: 坐标系
  • 提供位置、偏移量、速度等数据
struct DragExampleView: View {
    @State private var offset = CGSize.zero
    
    var body: some View {
        RoundedRectangle(cornerRadius: 20)
            .fill(Color.pink)
            .frame(width: 100, height: 100)
            .offset(offset)
            .gesture(
                DragGesture()
                    .onChanged { value in
                        withAnimation(.spring()) {
                            offset = value.translation
                        }
                    }
                    .onEnded { _ in
                        withAnimation(.spring()) {
                            offset = .zero
                        }
                    }
            )
    }
}

🔍 高级手势详解

MagnificationGesture（缩放手势）

检测捏合缩放操作，常用于图片查看器。

  • 返回缩放比例值
  • 通常与@GestureState配合使用
  • 支持缩放开始、变化、结束事件
struct MagnificationExampleView: View {
    @GestureState private var scale: CGFloat = 1.0
    @State private var finalScale: CGFloat = 1.0
    
    var body: some View {
        Image(systemName: "star.fill")
            .font(.system(size: 100))
            .foregroundColor(.yellow)
            .scaleEffect(finalScale * scale)
            .gesture(
                MagnificationGesture()
                    .updating($scale) { value, state, _ in
                        state = value
                    }
                    .onEnded { value in
                        finalScale *= value
                    }
            )
    }
}

RotationGesture（旋转手势）

检测旋转操作，返回旋转角度。

  • 返回角度值（弧度）
  • 可与@GestureState配合
  • 常用于自定义控件旋转
struct RotationExampleView: View {
    @GestureState private var angle: Angle = .degrees(0)
    @State private var finalAngle: Angle = .degrees(0)
    
    var body: some View {
        RoundedRectangle(cornerRadius: 10)
            .fill(LinearGradient(
                colors: [.blue, .purple],
                startPoint: .topLeading,
                endPoint: .bottomTrailing
            ))
            .frame(width: 150, height: 150)
            .rotationEffect(finalAngle + angle)
            .gesture(
                RotationGesture()
                    .updating($angle) { value, state, _ in
                        state = value
                    }
                    .onEnded { value in
                        finalAngle += value
                    }
            )
    }
}

📊 手势对比与选择指南

手势类型 主要用途 关键属性 返回值类型 适用场景
TapGesture 点击/轻触 count Void 按钮点击、项目选择
LongPressGesture 长按 minimumDuration Bool 上下文菜单、项目预览
DragGesture 拖拽 minimumDistance DragGesture.Value 列表重排序、滑动删除
MagnificationGesture 缩放 - CGFloat 图片查看、地图缩放
RotationGesture 旋转 - Angle 图片旋转、自定义控件

🎯 手势选择建议

  • 简单交互：优先使用TapGesture，最直观
  • 复杂交互：考虑组合手势（simultaneously, sequenced, exclusively）
  • 性能优化：使用@GestureState管理临时状态，避免不必要的视图更新
  • 用户体验：确保手势反馈及时，提供视觉反馈

🛠️ 实战技巧与最佳实践

1. 手势组合

SwiftUI允许将多个手势组合使用，创建更复杂的交互：

// 同时识别长按和拖拽
.gesture(
    LongPressGesture()
        .simultaneously(with: DragGesture())
)

// 先长按，然后拖拽（序列手势）
.gesture(
    LongPressGesture()
        .sequenced(before: DragGesture())
)

// 互斥手势（优先识别其中一个）
.gesture(
    TapGesture()
        .exclusively(before: LongPressGesture())
)

2. 使用@GestureState管理临时状态

@GestureState属性包装器专门用于手势的临时状态管理：

struct GestureStateExample: View {
    @GestureState private var isDetectingLongPress = false
    
    var body: some View {
        Circle()
            .fill(isDetectingLongPress ? Color.red : Color.green)
            .frame(width: 100, height: 100)
            .gesture(
                LongPressGesture(minimumDuration: 1)
                    .updating($isDetectingLongPress) { currentState, gestureState, transaction in
                        gestureState = currentState
                    }
            )
    }
}

综合示例：可交互卡片

struct InteractiveCardView: View {
    @State private var offset = CGSize.zero
    @State private var scale: CGFloat = 1.0
    @State private var rotation: Angle = .degrees(0)
    @State private var isTapped = false
    
    var body: some View {
        RoundedRectangle(cornerRadius: 25)
            .fill(
                LinearGradient(
                    colors: isTapped ? 
                        [.purple, .pink] : 
                        [.blue, .green],
                    startPoint: .topLeading,
                    endPoint: .bottomTrailing
                )
            )
            .frame(width: 200, height: 300)
            .overlay(
                VStack {
                    Image(systemName: isTapped ? "heart.fill" : "star.fill")
                        .font(.system(size: 60))
                        .foregroundColor(.white)
                    Text(isTapped ? "已喜欢!" : "点击试试")
                        .font(.title2)
                        .bold()
                        .foregroundColor(.white)
                }
            )
            .offset(offset)
            .scaleEffect(scale)
            .rotationEffect(rotation)
            .shadow(color: .black.opacity(0.2), radius: 10, x: 5, y: 5)
            // 组合手势：点击、拖拽、缩放、旋转
            .gesture(
                TapGesture()
                    .onEnded {
                        withAnimation(.spring()) {
                            isTapped.toggle()
                        }
                    }
            )
            .simultaneousGesture(
                DragGesture()
                    .onChanged { value in
                        offset = value.translation
                    }
                    .onEnded { _ in
                        withAnimation(.spring()) {
                            offset = .zero
                        }
                    }
            )
            .simultaneousGesture(
                MagnificationGesture()
                    .onChanged { value in
                        scale = value
                    }
                    .onEnded { _ in
                        withAnimation {
                            scale = 1.0
                        }
                    }
            )
    }
}
