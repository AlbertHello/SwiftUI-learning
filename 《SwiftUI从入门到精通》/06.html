SwiftUI 从入门到精通

第6章：列表与导航 —— 使用 List、ForEach、NavigationView、NavigationLink 构建列表和导航界面

本章概述

在移动应用开发中，列表展示和界面导航是两大核心交互模式。SwiftUI 通过声明式语法，提供了 List、ForEach、NavigationView 和 NavigationLink 等强大组件，让开发者能够以极简的代码构建出功能丰富、体验流畅的列表和导航界面。本章将深入讲解这些组件的用法、原理及最佳实践。

学习目标：掌握使用 SwiftUI 构建可滚动列表、实现界面间导航与数据传递，并理解其背后的数据驱动原理。

核心组件详解

List

用于创建可滚动的单列列表容器，是展示数据集合的首选组件。它自动适配 iOS 风格，并支持单元格操作、滑动删除等。

ForEach

一个视图构建器，用于根据集合数据动态生成多个视图。它是驱动 List 内容动态化的核心。

NavigationView

导航容器，为其内部的视图提供导航栈管理、导航栏等基础设施。通常作为界面的根容器。

NavigationLink

导航链接，放置在 List 单元格或其他视图中，点击后会将目标视图推入导航栈，实现界面跳转。

组件功能对比

组件 主要用途 关键特性 常用修饰符
List 创建可滚动列表布局 自动行分割、滑动删除、列表样式 .listStyle(), .onDelete()
ForEach 循环数据生成视图 要求数据可标识（Identifiable）， 高性能复用 id: \.self 或 使用 Identifiable 协议
NavigationView 导航容器，管理视图栈 导航栏标题、工具栏、双栏布局（iPad） .navigationTitle(), .navigationBarItems()
NavigationLink 触发导航到新视图 目标视图懒加载、支持编程导航 isActive, destination, label

基础实战：构建一个书籍列表应用

让我们通过一个完整的例子，将四个核心组件结合起来，构建一个简单的书籍列表应用，点击书籍可以进入详情页。

步骤 1: 定义数据模型

import SwiftUI

// 遵循 Identifiable 协议，便于 ForEach 使用
struct Book: Identifiable {
    let id = UUID()
    var title: String
    var author: String
    var isFavorited: Bool = false
}

// 准备示例数据
let sampleBooks = [
    Book(title: "SwiftUI 编程入门", author: "张三", isFavorited: true),
    Book(title: "深入浅出 iOS 设计", author: "李四"),
    Book(title: "算法之美", author: "王五"),
    Book(title: "移动应用测试", author: "赵六")
]

步骤 2: 创建列表视图 (ContentView)

struct ContentView: View {
    // 状态变量，管理书籍数据
    @State private var books = sampleBooks

    var body: some View {
        // 1. 导航容器
        NavigationView {
            // 2. 列表
            List {
                // 3. 动态生成行
                ForEach(books) { book in
                    // 4. 导航链接：点击单元格跳转到详情页
                    NavigationLink(destination: BookDetailView(book: book)) {
                        // 单元格内容
                        HStack {
                            VStack(alignment: .leading) {
                                Text(book.title)
                                    .font(.headline)
                                Text(book.author)
                                    .font(.subheadline)
                                    .foregroundColor(.gray)
                            }
                            Spacer()
                            if book.isFavorited {
                                Image(systemName: "star.fill")
                                    .foregroundColor(.yellow)
                            }
                        }
                        .padding(.vertical, 5)
                    }
                }
                .onDelete { indexSet in // 滑动删除
                    books.remove(atOffsets: indexSet)
                }
            }
            .navigationTitle("我的书库") // 设置导航栏标题
            .listStyle(InsetGroupedListStyle()) // 设置列表样式
        }
    }
}

步骤 3: 创建详情视图 (BookDetailView)

struct BookDetailView: View {
    let book: Book // 通过 NavigationLink 传递过来的数据

    var body: some View {
        VStack(spacing: 25) {
            Circle()
                .fill(Color("#FF9800").opacity(0.2))
                .frame(width: 150, height: 150)
                .overlay(
                    Text(String(book.title.prefix(1)))
                        .font(.system(size: 70, weight: .bold))
                        .foregroundColor(.orange)
                )

            Text(book.title)
                .font(.largeTitle)
                .fontWeight(.bold)
                .multilineTextAlignment(.center)

            Text("作者: ") + Text(book.author).fontWeight(.medium)
                .font(.title2)
                .foregroundColor(.blue)

            HStack {
                Label(book.isFavorited ? "已收藏" : "未收藏",
                       systemImage: book.isFavorited ? "star.fill" : "star")
                    .foregroundColor(book.isFavorited ? .yellow : .gray)
            }
            .padding()
            .background(Color.gray.opacity(0.1))
            .cornerRadius(10)

            Spacer()
        }
        .padding()
        .navigationTitle("书籍详情")
        .navigationBarTitleDisplayMode(.inline)
    }
}

架构与数据流示意图

数据流说明：数据模型 Book 作为唯一真相源。 ContentView 通过 @State 持有和管理书籍数组，并传递给 List 和 ForEach。当用户点击 NavigationLink 时，当前选中的 Book 实例被传递给 BookDetailView。任何对 @State 的修改（如删除）都会自动触发界面刷新。

关键技巧与最佳实践

  • 性能优化：对于超长列表，确保数据模型遵循 Identifiable 协议，或为 ForEach 显式指定 id: 参数，以帮助 SwiftUI 高效复用视图。
  • 导航控制：除了点击跳转，可以使用 @State 绑定一个 Bool 值或 NavigationLink 的 isActive 参数，实现编程式导航（如完成某个操作后自动返回）。
  • 列表操作：利用 .onDelete 实现滑动删除，结合 .onMove 可以实现拖动排序。
  • 样式定制：使用 .listStyle() 修饰符切换列表样式，如 PlainListStyle, GroupedListStyle, InsetGroupedListStyle（iOS 14+ 推荐）。
  • 兼容性：在 iOS 16+，考虑使用新的 NavigationStack 替代 NavigationView，以获得更强大的导航控制能力。

本章总结

List、ForEach、NavigationView、NavigationLink 是构建 SwiftUI 应用信息架构的四大支柱。通过它们的组合，我们可以轻松实现从静态列表到动态数据驱动列表，再到复杂导航流程的完整界面。掌握这些组件，意味着你已能够构建出大多数 App 的核心内容浏览框架。记住，SwiftUI 的核心思想是声明状态，驱动视图，在列表与导航的开发中，请始终关注数据源的设计与状态管理。
