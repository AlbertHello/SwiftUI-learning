第三讲：布局与容器详解

深入探索VStack、HStack、ZStack、ScrollView、LazyVStack、LazyHStack等核心布局容器

在SwiftUI中，布局容器是构建用户界面的基石。它们决定了视图在屏幕上的排列方式。本节课我们将系统学习SwiftUI中最重要、最常用的布局容器。

一、基础堆栈布局 (Basic Stacks)

堆栈是SwiftUI中最基础的布局容器，用于在单个维度上排列子视图。

1. VStack - 垂直堆栈

将子视图沿垂直方向（从上到下）排列。

import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack(spacing: 20) { // spacing控制子视图间距
            Text("顶部标题")
                .font(.largeTitle)
                .foregroundColor(.blue)
            
            Image(systemName: "star.fill")
                .font(.system(size: 50))
                .foregroundColor(.yellow)
            
            Button("点击我") {
                print("按钮被点击")
            }
            .padding()
            .background(Color.green)
            .foregroundColor(.white)
            .cornerRadius(10)
        }
        .padding() // 内边距
    }
}

2. HStack - 水平堆栈

将子视图沿水平方向（从左到右）排列。

struct ProfileView: View {
    var body: some View {
        HStack(alignment: .center, spacing: 15) {
            Image(systemName: "person.circle.fill")
                .font(.system(size: 60))
                .foregroundColor(.blue)
            
            VStack(alignment: .leading, spacing: 5) {
                Text("张三")
                    .font(.title2)
                    .fontWeight(.bold)
                Text("iOS开发工程师")
                    .font(.subheadline)
                    .foregroundColor(.gray)
                Text("热爱编程与设计")
                    .font(.caption)
                    .foregroundColor(.secondary)
            }
            
            Spacer() // 弹性空间，将内容推到左边
            
            Image(systemName: "chevron.right")
                .foregroundColor(.gray)
        }
        .padding()
    }
}

3. ZStack - 深度堆栈

将子视图沿Z轴（垂直于屏幕）重叠排列，常用于创建层叠效果。

struct BadgeView: View {
    var body: some View {
        ZStack {
            Circle()
                .fill(Color.blue)
                .frame(width: 100, height: 100)
            
            Circle()
                .fill(Color.white)
                .frame(width: 80, height: 80)
            
            Text("NEW")
                .font(.title)
                .fontWeight(.black)
                .foregroundColor(.blue)
            
            // 右上角小红点
            Circle()
                .fill(Color.red)
                .frame(width: 20, height: 20)
                .offset(x: 35, y: -35) // 偏移位置
        }
    }
}

基础堆栈对比表

容器 排列方向 主要用途 常用修饰符
VStack 垂直（Y轴） 表单、列表、垂直导航 spacing, alignment, padding
HStack 水平（X轴） 导航栏、工具栏、水平菜单 spacing, alignment, padding
ZStack 深度（Z轴） 重叠视图、徽章、浮动按钮 alignment, offset, zIndex

二、滚动视图 (ScrollView)

当内容超出屏幕范围时，ScrollView提供滚动查看功能。

struct ArticleListView: View {
    let articles = ["SwiftUI入门指南", "布局容器详解", "状态管理", "动画与过渡", "网络请求", "数据持久化", "测试与调试", "上架App Store"]
    
    var body: some View {
        ScrollView {
            VStack(spacing: 15) {
                ForEach(articles, id: \.self) { article in
                    HStack {
                        Image(systemName: "doc.text.fill")
                            .foregroundColor(.blue)
                            .frame(width: 30)
                        
                        Text(article)
                            .font(.headline)
                        
                        Spacer()
                        
                        Image(systemName: "chevron.right")
                            .foregroundColor(.gray)
                            .font(.caption)
                    }
                    .padding()
                    .background(Color(.systemGray6))
                    .cornerRadius(10)
                    .shadow(color: .black.opacity(0.05), radius: 2, x: 0, y: 1)
                }
            }
            .padding()
        }
        .frame(maxHeight: 400) // 限制最大高度
    }
}

💡 提示：ScrollView默认是垂直滚动的。如果要创建水平滚动视图，可以使用ScrollView(.horizontal)。

三、惰性堆栈 (Lazy Stacks)

LazyVStack和LazyHStack只在需要时才创建视图，适合显示大量数据，能显著提升性能。

LazyVStack vs VStack 性能对比

struct ProductListView: View {
    // 模拟大量数据
    let products = (1...1000).map { "产品 #\($0)" }
    
    var body: some View {
        ScrollView {
            LazyVStack(spacing: 12) { // 使用LazyVStack替代VStack
                ForEach(products, id: \.self) { product in
                    ProductRow(name: product)
                        .onAppear {
                            // 可以在这里触发分页加载等操作
                            print("\(product) 出现在屏幕上")
                        }
                }
            }
            .padding()
        }
    }
}

struct ProductRow: View {
    let name: String
    
    var body: some View {
        HStack {
            RoundedRectangle(cornerRadius: 8)
                .fill(Color.blue.opacity(0.2))
                .frame(width: 50, height: 50)
                .overlay(
                    Text(String(name.last!))
                        .font(.title2)
                        .fontWeight(.bold)
                        .foregroundColor(.blue)
                )
            
            VStack(alignment: .leading, spacing: 4) {
                Text(name)
                    .font(.headline)
                Text("产品描述信息...")
                    .font(.caption)
                    .foregroundColor(.gray)
                    .lineLimit(1)
            }
            
            Spacer()
            
            Text("¥999")
                .font(.headline)
                .foregroundColor(.orange)
        }
        .padding()
        .background(Color(.systemBackground))
        .cornerRadius(12)
        .shadow(color: .black.opacity(0.05), radius: 3, x: 0, y: 1)
    }
}

LazyHStack 示例

struct HorizontalGalleryView: View {
    let images = ["photo1", "photo2", "photo3", "photo4", "photo5", "photo6"]
    
    var body: some View {
        ScrollView(.horizontal, showsIndicators: false) {
            LazyHStack(spacing: 15) {
                ForEach(images, id: \.self) { imageName in
                    RoundedRectangle(cornerRadius: 15)
                        .fill(
                            LinearGradient(
                                gradient: Gradient(colors: [.blue, .purple]),
                                startPoint: .topLeading,
                                endPoint: .bottomTrailing
                            )
                        )
                        .frame(width: 150, height: 200)
                        .overlay(
                            Text(imageName)
                                .font(.headline)
                                .foregroundColor(.white)
                                .padding(8)
                                .background(Color.black.opacity(0.5))
                                .cornerRadius(8)
                        )
                        .shadow(radius: 5)
                }
            }
            .padding()
        }
        .frame(height: 220)
    }
}

四、布局容器选择指南

根据不同的使用场景，选择合适的布局容器：

  1. 简单垂直布局 → 使用 VStack
  2. 简单水平布局 → 使用 HStack
  3. 视图重叠 → 使用 ZStack
  4. 内容可能超出屏幕 → 使用 ScrollView 包裹堆栈
  5. 大量数据列表 → 使用 LazyVStack 或 LazyHStack
  6. 复杂布局 → 组合使用多个容器

综合示例：社交应用帖子布局

struct SocialMediaPostView: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            // 顶部用户信息 - 水平布局
            HStack {
                ZStack {
                    Circle()
                        .fill(Color.blue.opacity(0.2))
                        .frame(width: 50, height: 50)
                    
                    Text("用户")
                        .font(.headline)
                        .foregroundColor(.blue)
                }
                
                VStack(alignment: .leading, spacing: 4) {
                    Text("李四")
                        .font(.headline)
                    Text("2小时前 · 公开")
                        .font(.caption)
                        .foregroundColor(.gray)
                }
                
                Spacer()
                
                Button(action: {}) {
                    Image(systemName: "ellipsis")
                        .foregroundColor(.gray)
                }
            }
            
            // 帖子内容
            Text("今天学习了SwiftUI的布局容器，VStack、HStack、ZStack真的非常强大！")
                .font(.body)
                .lineSpacing(4)
            
            // 图片网格 - 使用LazyVGrid或HStack/VStack组合
            HStack(spacing: 5) {
                RoundedRectangle(cornerRadius: 10)
                    .fill(Color.blue.opacity(0.3))
                    .aspectRatio(1, contentMode: .fit)
                
                RoundedRectangle(cornerRadius: 10)
                    .fill(Color.green.opacity(0.3))
                    .aspectRatio(1, contentMode: .fit)
            }
            .frame(height: 150)
            
            // 互动按钮 - 水平布局
            HStack(spacing: 20) {
                Button(action: {}) {
                    HStack(spacing: 5) {
                        Image(systemName: "hand.thumbsup")
                        Text("点赞")
                    }
                }
                
                Button(action: {}) {
                    HStack(spacing: 5) {
                        Image(systemName: "message")
                        Text("评论")
                    }
                }
                
                Button(action: {}) {
                    HStack(spacing: 5) {
                        Image(systemName: "arrowshape.turn.up.right")
                        Text("分享")
                    }

            .foregroundColor(.gray)

        .padding()
        .background(Color(.systemBackground))
        .cornerRadius(15)
        .shadow(color: .black.opacity(0.05), radius: 5, x: 0, y: 2)
    }
}

五、SwiftUI布局系统架构

SwiftUI的布局系统遵循以下流程：

  • 父视图提议尺寸：父视图向子视图提供可用空间
  • 子视图计算需求：子视图根据自身内容计算所需尺寸
  • 父视图放置子视图：父视图在可用空间内放置子视图
  • 递归过程：这个过程从根视图递归到所有子视图
