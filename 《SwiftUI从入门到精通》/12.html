第12讲：视图组合与复用

ViewBuilder、@ViewBuilder、自定义可复用组件构建

一、核心概念：为什么需要视图组合？

在SwiftUI中，视图组合(View Composition)是将多个小型、单一的视图组合成更大、更复杂视图的技术。这遵循了“单一职责”和“关注点分离”的设计原则。

主要优势：

  • 可维护性：每个小组件只负责一个功能，易于理解和修改。
  • 可复用性：构建一次，可在多个地方重复使用。
  • 可测试性：小型独立视图更容易进行单元测试。
  • 代码清晰度：将复杂界面分解，使代码结构更清晰。

二、ViewBuilder：SwiftUI的声明式语法核心

ViewBuilder是一个结果构建器(Result Builder)，它允许我们以声明式的方式将多个视图组合成一个视图。它是SwiftUI DSL（领域特定语言）的基石。

关键特性： ViewBuilder 可以将多个子视图（最多10个）组织成一个返回单个 some View 的闭包。它支持条件判断（if/else）和有限循环（ForEach）。

import SwiftUI

// ViewBuilder 的典型使用场景：VStack, HStack, Group 等容器的内容闭包
struct ContentView: View {
    var isLoggedIn: Bool = true

    var body: some View {
        VStack { // 这里的闭包隐式使用了 ViewBuilder
            Text("欢迎使用")
                .font(.largeTitle)
            Image(systemName: "star.fill")
                .foregroundColor(.yellow)

            if isLoggedIn {
                Text("用户已登录")
                    .foregroundColor(.green)
            } else {
                Button("点击登录") {
                    print("登录操作")
                }
            }

            ForEach(1...3, id: \.self) { number in
                Text("项目 \(number)")
            }
        }
    }
}

三、@ViewBuilder 属性包装器

当我们需要自定义一个接受多个视图作为参数的视图或函数时，需要使用 @ViewBuilder 属性包装器来标记闭包参数。

@ViewBuilder 作为父视图与多个子视图之间的桥梁

// 自定义一个接受 @ViewBuilder 的容器视图
struct CustomCard<Content: View>: View {
    let title: String
    let content: Content // 泛型 Content 代表一组视图

    // 使用 @ViewBuilder 初始化 content 闭包
    init(title: String, @ViewBuilder content: () -> Content) {
        self.title = title
        self.content = content()
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 10) {
            Text(title)
                .font(.headline)
                .foregroundColor(.white)
                .padding(.horizontal)
                .frame(maxWidth: .infinity, alignment: .leading)
                .background(Color.blue)

            content // 这里放置通过 @ViewBuilder 传入的所有子视图
                .padding()

        }
        .background(Color(.systemBackground))
        .cornerRadius(12)
        .shadow(radius: 3)
    }
}

// 使用示例
struct ExampleView: View {
    var body: some View {
        CustomCard(title: "学生信息卡") {
            Text("姓名：小明")
            Text("年龄：12岁")
            HStack {
                Image(systemName: "graduationcap.fill")
                Text("五年级三班")
            }
            .foregroundColor(.orange)
        }
        .padding()
    }
}

四、构建自定义可复用组件

将常用的UI模式和功能封装成独立的、可配置的组件，是提高开发效率的关键。

设计原则： 组件应遵循“开放-封闭”原则，对扩展开放，对修改封闭。通过参数配置组件行为，而非修改内部代码。

4.1 可配置的按钮组件示例

struct PrimaryButton: View {
    let title: String
    let iconName: String?
    let action: () -> Void
    var backgroundColor: Color = .blue
    var foregroundColor: Color = .white

    var body: some View {
        Button(action: action) {
            HStack(spacing: 8) {
                if let iconName = iconName {
                    Image(systemName: iconName)
                }
                Text(title)
                    .fontWeight(.semibold)
            }
            .padding(.horizontal, 20)
            .padding(.vertical, 12)
            .background(backgroundColor)
            .foregroundColor(foregroundColor)
            .cornerRadius(10)
        }
    }
}

// 使用
struct ButtonDemo: View {
    var body: some View {
        VStack(spacing: 20) {
            PrimaryButton(title: "提交作业", iconName: "paperplane.fill", action: {
                print("作业已提交")
            })
            PrimaryButton(title: "取消", iconName: "xmark.circle", action: {},
                         backgroundColor: .gray, foregroundColor: .white)
        }
    }
}

4.2 复杂组合：信息面板组件

struct InfoPanel<Header: View, Footer: View>: View {
    let header: Header
    let footer: Footer

    init(@ViewBuilder header: () -> Header,
         @ViewBuilder footer: () -> Footer) {
        self.header = header()
        self.footer = footer()
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            header
                .padding()
                .background(Color.orange.opacity(0.2))

            Divider()

            footer
                .padding()
                .background(Color.green.opacity(0.1))
        }
        .cornerRadius(12)
        .overlay(
            RoundedRectangle(cornerRadius: 12)
                .stroke(Color.orange, lineWidth: 2)
        )
    }
}

// 使用
struct PanelDemo: View {
    var body: some View {
        InfoPanel {
            HStack {
                Image(systemName: "info.circle.fill")
                Text("重要通知")
                    .font(.title2)
                    .bold()
            }
            .foregroundColor(.orange)
        } footer: {
            VStack(alignment: .leading, spacing: 10) {
                Text("明天上午9点有数学测验。")
                Text("请同学们带好尺子和圆规。")
                PrimaryButton(title: "我知道了", iconName: "checkmark.circle", action: {})
            }
        }
        .padding()
    }
}

五、最佳实践与对比

技术 用途 优点 适用场景
ViewBuilder (隐式) SwiftUI容器（VStack等）的默认内容构建器 无需显式声明，语法简洁 标准布局，子视图数量明确
@ViewBuilder (显式) 自定义组件接受多个视图作为参数 极大增强组件灵活性和复用性 构建通用容器、卡片、面板等
自定义组件（无ViewBuilder） 固定结构、功能单一的UI元素 性能最优，类型安全 按钮、标签、图标等基础元素
泛型 + @ViewBuilder 高度灵活、类型安全的复杂组件 最大程度的复用和类型安全 高级UI框架、设计系统组件

关键要点总结：

  1. 从小组件开始构建，逐步组合成复杂界面。
  2. 善用 @ViewBuilder 让自定义组件像原生容器一样灵活。
  3. 为组件提供合理的默认值，并通过参数暴露可定制点。
  4. 使用泛型（<Content: View>）提高组件的通用性。
  5. 为复杂组件编写使用示例和文档注释。

六、综合实战：构建一个“学生任务卡片”

让我们运用所学，构建一个可在班级应用中复用的任务卡片组件。

struct StudentTaskCard<Actions: View>: View {
    let taskName: String
    let subject: String
    let dueDate: Date
    let isCompleted: Bool
    let actions: Actions

    init(taskName: String,
         subject: String,
         dueDate: Date,
         isCompleted: Bool = false,
         @ViewBuilder actions: () -> Actions) {
        self.taskName = taskName
        self.subject = subject
        self.dueDate = dueDate
        self.isCompleted = isCompleted
        self.actions = actions()
    }

    private var dueDateString: String {
        let formatter = DateFormatter()
        formatter.dateFormat = "MM月dd日 HH:mm"
        return formatter.string(from: dueDate)
    }

    var body: some View {
        VStack(alignment: .leading, spacing: 15) {
            // 头部：科目和状态
            HStack {
                Circle()
                    .fill(isCompleted ? Color.green : Color.orange)
                    .frame(width: 12, height: 12)
                Text(subject)
                    .font(.caption)
                    .fontWeight(.bold)
                    .foregroundColor(.secondary)
                Spacer()
                Text(isCompleted ? "已完成" : "进行中")
                    .font(.caption)
                    .padding(.horizontal, 8)
                    .padding(.vertical, 4)
                    .background(isCompleted ? Color.green.opacity(0.2) : Color.orange.opacity(0.2))
                    .cornerRadius(4)
            }

            // 任务名称
            Text(taskName)
                .font(.headline)

            // 截止时间
            Label(dueDateString, systemImage: "calendar.badge.clock")
                .font(.subheadline)
                .foregroundColor(.blue)

            // 自定义操作区域
            if !isCompleted {
                Divider()
                HStack {
                    actions // 由使用者传入的按钮组
                }
            }
        }
        .padding()
        .background(Color(.systemBackground))
        .cornerRadius(16)
        .overlay(
            RoundedRectangle(cornerRadius: 16)
                .stroke(isCompleted ? Color.green : Color.gray.opacity(0.3), lineWidth: 2)
        )
        .opacity(isCompleted ? 0.8 : 1.0)
    }
}

struct TaskBoardView: View {
    let tasks = [
        (name: "完成数学练习册第5页", subject: "数学", due: Date().addingTimeInterval(86400), completed: false),
        (name: "背诵古诗《春晓》", subject: "语文", due: Date().addingTimeInterval(172800), completed: true),
        (name: "制作太阳系模型", subject: "科学", due: Date().addingTimeInterval(259200), completed: false)
    ]

    var body: some View {
        ScrollView {
            VStack(spacing: 20) {
                ForEach(tasks, id: \.name) { task in
                    StudentTaskCard(
                        taskName: task.name,
                        subject: task.subject,
                        dueDate: task.due,
                        isCompleted: task.completed
                    ) {
                        // 这里可以灵活传入任何视图作为操作按钮
                        if !task.completed {
                            PrimaryButton(title: "标记完成", iconName: "checkmark", action: {
                                print("标记任务完成: \(task.name)")
                            })
                            .frame(maxWidth: .infinity)

                            Button("请求延期") {
                                print("请求延期: \(task.name)")
                            }
                            .foregroundColor(.orange)
                        }
                    }
                }
            }
            .padding()
        }
    }
}
