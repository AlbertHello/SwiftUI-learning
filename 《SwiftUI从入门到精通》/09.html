一、Animatable协议：动画的数学核心

Animatable协议是SwiftUI动画系统的数学基础。任何遵循此协议的类型都可以被动画化，因为它定义了如何对值进行插值计算。

1.1 协议定义与原理

Animatable协议非常简单，只要求一个计算属性：

public protocol Animatable {
    var animatableData: Self.AnimatableData { get set }
}

public protocol VectorArithmetic: AdditiveArithmetic {
    func scale(by rhs: Double)
    var magnitudeSquared: Double { get }
}
核心概念： AnimatableData必须遵循VectorArithmetic协议，这意味着它必须支持加、减、缩放等数学运算，这样SwiftUI才能在两个值之间进行平滑的插值计算。

1.2 实现自定义Animatable

让我们创建一个自定义的形状，实现Animatable协议：

struct WavyRectangle: Shape {
    var waveOffset: Double  // 波浪偏移量
    var amplitude: Double   // 振幅
    var frequency: Double   // 频率
    
    var animatableData: AnimatablePair<Double, AnimatablePair<Double, Double>> {
        get {
            AnimatablePair(waveOffset, AnimatablePair(amplitude, frequency))
        }
        set {
            waveOffset = newValue.first
            amplitude = newValue.second.first
            frequency = newValue.second.second
        }
    }
    
    func path(in rect: CGRect) -> Path {
        var path = Path()
        let width = rect.width
        let height = rect.height
        
        // 移动到起点
        path.move(to: CGPoint(x: 0, y: height / 2))
        
        // 绘制波浪线
        for x in stride(from: 0, through: width, by: 1) {
            let relativeX = x / width
            let y = height / 2 + sin(relativeX * frequency * .pi * 2 + waveOffset) * amplitude
            path.addLine(to: CGPoint(x: x, y: y))
        }
        
        // 闭合路径
        path.addLine(to: CGPoint(x: width, y: height))
        path.addLine(to: CGPoint(x: 0, y: height))
        path.closeSubpath()
        
        return path
    }
}
注意： 当有多个动画属性时，可以使用AnimatablePair、AnimatableTriplet或创建自定义的VectorArithmetic类型来组合它们。

二、GeometryEffect：几何变换的利器

GeometryEffect协议允许你创建可以应用于任何视图的几何变换效果，并且这些效果可以被动画化。

2.1 GeometryEffect协议解析

protocol GeometryEffect: Animatable, ViewModifier {
    func effectValue(size: CGSize) -> ProjectionTransform
}

关键特性

  • 同时遵循Animatable和ViewModifier协议
  • 可以修改视图的几何属性
  • 支持动画过渡
  • 可以组合使用
  • 性能高效

常见用途

  • 2D/3D旋转
  • 缩放和倾斜
  • 透视变换
  • 自定义扭曲效果
  • 路径跟随动画

2.2 创建自定义GeometryEffect

实现一个跳跃效果：

struct JumpEffect: GeometryEffect {
    var height: CGFloat  // 跳跃高度
    var phase: CGFloat   // 相位 (0-1)
    
    var animatableData: AnimatablePair<CGFloat, CGFloat> {
        get { AnimatablePair(height, phase) }
        set {
            height = newValue.first
            phase = newValue.second
        }
    }
    
    func effectValue(size: CGSize) -> ProjectionTransform {
        // 计算跳跃曲线 (抛物线)
        let jumpHeight = -abs(sin(phase * .pi * 2)) * height
        
        // 创建变换矩阵
        var transform = CGAffineTransform(translationX: 0, y: jumpHeight)
        
        // 添加轻微旋转模拟真实跳跃
        let rotation = sin(phase * .pi * 2) * 5  // ±5度
        transform = transform.rotated(by: rotation * .pi / 180)
        
        return ProjectionTransform(transform)
    }
}

// 使用示例
struct JumpingView: View {
    @State private var isJumping = false
    
    var body: some View {
        Circle()
            .fill(Color.orange)
            .frame(width: 100, height: 100)
            .modifier(JumpEffect(
                height: isJumping ? 50 : 0,
                phase: isJumping ? 1 : 0
            ))
            .onTapGesture {
                withAnimation(.spring(response: 0.5, dampingFraction: 0.3)) {
                    isJumping.toggle()
                }
            }
    }
}

三、自定义动画曲线

SwiftUI允许你创建自定义的动画时间曲线，实现独特的动画节奏。

3.1 实现Animation协议

struct BounceAnimation: CustomAnimation {
    let duration: TimeInterval
    let bounces: Int
    
    func animate(value: Double, time: TimeInterval) -> Double? {
        let progress = time / duration
        
        guard progress >= 0 && progress <= 1 else { return nil }
        
        // 弹性曲线公式
        let decay = exp(-3.0 * progress)
        let oscillation = sin(progress * .pi * 2 * Double(bounces))
        
        return 1 - decay * (1 - progress) * (1 + oscillation * 0.3)
    }
    
    var velocity: Double { 1.0 / duration }
}

// 扩展以便使用
extension Animation {
    static var bounce: Animation {
        .timingCurve(0.68, -0.6, 0.32, 1.6, duration: 0.8)
    }
    
    static func customBounce(duration: TimeInterval = 0.8, bounces: Int = 3) -> Animation {
        .timingCurve(0.68, -0.6, 0.32, 1.6, duration: duration)
    }
}

3.2 动画曲线对比

动画类型 曲线特征 适用场景 代码示例

缓入缓出 慢-快-慢 自然物体运动 .easeInOut(duration: 1)

四、复杂动画效果实现

结合前面所学，实现一个综合的复杂动画示例。

4.1 粒子系统动画

struct ParticleSystemView: View {
    @State private var isActive = false
    let particleCount = 50
    
    var body: some View {
        ZStack {
            // 背景
            RoundedRectangle(cornerRadius: 20)
                .fill(LinearGradient(
                    gradient: Gradient(colors: [.blue, .purple]),
                    startPoint: .topLeading,
                    endPoint: .bottomTrailing
                ))
                .frame(width: 300, height: 300)
            
            // 粒子
            ForEach(0..<particleCount, id: \.self) { index in
                ParticleView(index: index, isActive: isActive)
            }
            
            // 控制按钮
            Button(action: {
                withAnimation(.easeInOut(duration: 2)) {
                    isActive.toggle()
                }
            }) {
                Text(isActive ? "停止粒子" : "启动粒子")
                    .font(.headline)
                    .foregroundColor(.white)
                    .padding()
                    .background(Capsule().fill(Color.orange))
            }
            .offset(y: 130)
        }
    }
}

struct ParticleView: View {
    let index: Int
    let isActive: Bool
    
    @State private var scale: CGFloat = 0
    @State private opacity: Double = 0
    
    var body: some View {
        Circle()
            .fill(Color.white)
            .frame(width: 8, height: 8)
            .scaleEffect(scale)
            .opacity(opacity)
            .modifier(ParticleMotionEffect(
                index: index,
                isActive: isActive
            ))
            .onAppear {
                let delay = Double(index) * 0.02
                
                withAnimation(.spring(response: 0.6, dampingFraction: 0.5)
                    .delay(delay)) {
                    scale = isActive ? 1 : 0
                    opacity = isActive ? 1 : 0
                }
            }
            .onChange(of: isActive) { newValue in
                let delay = Double(index) * 0.02
                
                withAnimation(.spring(response: 0.6, dampingFraction: 0.5)
                    .delay(newValue ? delay : 0)) {
                    scale = newValue ? 1 : 0
                    opacity = newValue ? 1 : 0
                }
            }
    }
}

struct ParticleMotionEffect: GeometryEffect {
    let index: Int
    let isActive: Bool
    
    var animatableData: CGFloat {
        get { isActive ? 1 : 0 }
        set { }
    }
    
    func effectValue(size: CGSize) -> ProjectionTransform {
        let angle = Double(index) / 50 * .pi * 2
        let radius: CGFloat = isActive ? 100 : 0
        
        let x = cos(angle) * radius
        let y = sin(angle) * radius
        
        let translation = CGAffineTransform(translationX: x, y: y)
        
        // 添加旋转
        let rotation = CGAffineTransform(rotationAngle: angle * 2)
        
        return ProjectionTransform(translation.concatenating(rotation))
    }
}
