第24课：辅助功能

为SwiftUI视图添加无障碍支持（Accessibility）

一、什么是辅助功能？

辅助功能（Accessibility）旨在让应用程序对所有人（包括视力、听力、运动或认知障碍人士）都可使用。在SwiftUI中，构建无障碍应用是框架的核心设计原则之一。

核心目标：通过 VoiceOver、开关控制、缩放显示等辅助技术，确保每个用户都能平等地访问和使用你的App。

二、关键无障碍修饰符

修饰符 作用 示例
.accessibilityLabel(_:) 为视图提供描述性标签，VoiceOver会朗读此标签。 “提交按钮”
.accessibilityHint(_:) 提供额外操作提示，解释操作结果。 “双击以发送消息”
.accessibilityValue(_:) 描述视图的当前值（如滑块值、进度）。 “50%”
.accessibilityAddTraits(_:) 添加无障碍特性（如按钮、标题、选中状态）。 .isButton, .isHeader
.accessibilityElement(children:) 控制子视图的无障碍组合方式。 .combine, .contain
.accessibilityHidden(_:) 隐藏视图，使其对辅助技术不可见。 true 或 false

三、实战代码示例

1. 基础按钮无障碍化

import SwiftUI

struct AccessibleButtonView: View {
    @State private var count = 0
    
    var body: some View {
        VStack(spacing: 20) {
            Text("点击次数: \(count)")
                .font(.title)
                .accessibilityLabel("当前点击次数")
                .accessibilityValue("\(count) 次")
            
            Button(action: {
                count += 1
            }) {
                Image(systemName: "plus.circle.fill")
                Text("增加")
            }
            .padding()
            .background(Color.blue)
            .foregroundColor(.white)
            .cornerRadius(10)
            // 关键无障碍修饰符
            .accessibilityLabel("增加按钮")
            .accessibilityHint("点击此按钮将使计数加一")
            .accessibilityAddTraits(.isButton)
        }
        .padding()
    }
}

2. 自定义视图组无障碍

struct ProfileView: View {
    var body: some View {
        VStack(alignment: .leading) {
            HStack {
                Image(systemName: "person.circle.fill")
                    .font(.system(size: 50))
                    .foregroundColor(.green)
                VStack(alignment: .leading) {
                    Text("小明")
                        .font(.title)
                        .accessibilityAddTraits(.isHeader)
                    Text("小学生，五年级")
                        .font(.subheadline)
                        .foregroundColor(.secondary)
                }
            }
            // 将整个HStack作为一个无障碍元素处理
            .accessibilityElement(children: .combine)
            .accessibilityLabel("用户资料：小明，小学生，五年级")
            
            Divider()
            
            Text("兴趣爱好：阅读、编程、足球")
                .padding(.top)
                .accessibilityLabel("兴趣爱好：阅读、编程、足球")
        }
        .padding()
        .background(Color(.systemBackground))
        .cornerRadius(12)
        .shadow(radius: 2)
    }
}

四、最佳实践清单

  • 语义化标签：为所有交互元素提供准确、简洁的 accessibilityLabel。
  • 合理分组：使用 .accessibilityElement(children: .combine) 将逻辑相关的视图合并为一个无障碍元素。
  • 提供提示：对复杂操作使用 accessibilityHint，但避免重复标签内容。
  • 动态值更新：当视图内容变化时（如进度条、计数器），及时更新 accessibilityValue。
  • 隐藏装饰性内容：对纯装饰性、无信息的图像使用 .accessibilityHidden(true)。
  • 测试：始终在真机上使用 VoiceOver 和 开关控制 进行测试。

五、常见无障碍特性（Traits）

特性（Traits）帮助辅助技术正确识别和描述UI元素的角色与状态。

  1. .isButton - 标识元素为按钮。
  2. .isHeader - 标识标题，帮助用户导航内容结构。
  3. .isLink - 标识链接元素。
  4. .isImage - 标识图像元素。
  5. .isSelected - 标识元素当前被选中。
  6. .isSearchField - 标识搜索框。
  7. .playsSound - 表示元素被激活时会播放声音。
  8. .isKeyboardKey - 标识键盘键。

六、调试与测试

在Xcode中，你可以使用 无障碍检查器（Accessibility Inspector） 来预览和调试应用的无障碍属性。同时，务必在真实设备上开启 VoiceOver 进行完整的功能测试。

测试口诀：“眼看标签清不清，耳听朗读顺不顺，手控开关灵不灵，心感逻辑明不明。”
