二、Layout协议详解

Layout协议是SwiftUI 4.0引入的强大工具，允许开发者创建完全自定义的布局容器。

核心方法

方法名 作用 调用时机
sizeThatFits(proposal:subviews:cache:) 计算布局容器的理想尺寸 布局系统询问容器需要多大空间时
placeSubviews(in:proposal:subviews:cache:) 将子视图放置到指定区域 确定容器尺寸后，安排子视图位置
makeCache(subviews:) 创建缓存以提高性能 布局首次创建或子视图变化时
updateCache(_:subviews:) 更新缓存数据 子视图或环境变化时

💡 关键概念

提案(Proposal): SwiftUI布局系统的核心概念，父视图向子视图询问尺寸时使用的"建议尺寸"，子视图可以接受、拒绝或修改这个提案。

缓存(Cache): 可选但重要的性能优化手段，用于存储计算中间结果，避免重复计算。

三、实现自定义布局容器

创建一个自定义布局需要遵循以下步骤：

  1. 创建一个遵循Layout协议的结构体
  2. 实现必需的sizeThatFits和placeSubviews方法
  3. 可选实现缓存方法以优化性能
  4. 在SwiftUI视图中使用你的自定义布局

基础模板示例

import SwiftUI

struct MyCustomLayout: Layout {
    // 1. 计算容器尺寸
    func sizeThatFits(
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout ()
    ) -> CGSize {
        // 根据子视图和提案计算并返回容器尺寸
        let totalWidth = subviews.reduce(0) { sum, subview in
            let size = subview.sizeThatFits(.unspecified)
            return sum + size.width
        }
        let maxHeight = subviews.map { $0.sizeThatFits(.unspecified).height }.max() ?? 0
        
        return CGSize(width: totalWidth, height: maxHeight)
    }
    
    // 2. 放置子视图
    func placeSubviews(
        in bounds: CGRect,
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout ()
    ) {
        var x = bounds.minX
        
        for subview in subviews {
            let size = subview.sizeThatFits(.unspecified)
            let point = CGPoint(x: x, y: bounds.midY - size.height / 2)
            
            subview.place(at: point, anchor: .topLeading, proposal: .unspecified)
            x += size.width
        }
    }
}

// 使用示例
struct ContentView: View {
    var body: some View {
        MyCustomLayout {
            Text("第一个视图")
                .padding()
                .background(Color.orange)
            Text("第二个")
                .padding()
                .background(Color.blue)
            Text("第三个视图")
                .padding()
                .background(Color.green)
        }
        .border(Color.gray)
    }
}

四、实战：流式布局实现

流式布局（Flow Layout）也称为瀑布流或自动换行布局，常用于标签、关键词展示等场景。

流式布局特点

  • 子视图水平排列
  • 空间不足时自动换行
  • 每行高度可能不同
  • 常用于标签云

实现要点

  • 跟踪当前行位置
  • 计算每行最大高度
  • 处理换行逻辑
  • 支持水平和垂直间距

完整实现代码

struct FlowLayout: Layout {
    var horizontalSpacing: CGFloat = 8
    var verticalSpacing: CGFloat = 8
    
    func sizeThatFits(
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout ()
    ) -> CGSize {
        let maxWidth = proposal.width ?? .infinity
        var height: CGFloat = 0
        var rowWidth: CGFloat = 0
        var rowHeight: CGFloat = 0
        
        for subview in subviews {
            let size = subview.sizeThatFits(.unspecified)
            
            if rowWidth + size.width > maxWidth {
                // 需要换行
                height += rowHeight + verticalSpacing
                rowWidth = size.width
                rowHeight = size.height
            } else {
                // 继续当前行
                rowWidth += size.width + horizontalSpacing
                rowHeight = max(rowHeight, size.height)
            }
        }
        
        // 加上最后一行的高度
        height += rowHeight
        
        return CGSize(
            width: proposal.width ?? rowWidth,
            height: proposal.height ?? height
        )
    }
    
    func placeSubviews(
        in bounds: CGRect,
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout ()
    ) {
        let maxWidth = bounds.width
        var x = bounds.minX
        var y = bounds.minY
        var rowHeight: CGFloat = 0
        
        for subview in subviews {
            let size = subview.sizeThatFits(.unspecified)
            
            if x + size.width > bounds.maxX {
                // 换行
                x = bounds.minX
                y += rowHeight + verticalSpacing
                rowHeight = 0
            }
            
            subview.place(
                at: CGPoint(x: x, y: y),
                anchor: .topLeading,
                proposal: .unspecified
            )
            
            x += size.width + horizontalSpacing
            rowHeight = max(rowHeight, size.height)
        }
    }
}

    let tags = ["SwiftUI", "iOS开发", "自定义布局", "Layout协议", "流式布局", "网格布局", "UI设计", "移动应用"]
    
    var body: some View {
        FlowLayout(horizontalSpacing: 10, verticalSpacing: 10) {
            ForEach(tags, id: \.self) { tag in
                Text(tag)

六、性能优化与最佳实践

📊 性能对比

合理使用缓存可以显著提升自定义布局的性能，特别是在子视图数量多或布局复杂的情况下。

优化技巧 说明 效果
使用缓存 在makeCache和updateCache中存储中间计算结果 减少重复计算，提升性能30-50%
批量计算 在sizeThatFits中一次性计算所有位置 避免多次遍历子视图
合理使用提案 根据父视图提案选择合适的计算策略 提高布局响应速度
避免强制布局 只在必要时调用sizeThatFits 减少不必要的布局传递

缓存优化示例

struct OptimizedFlowLayout: Layout {
    var spacing: CGFloat = 8
    
    // 定义缓存类型
    struct Cache {
        var sizes: [CGSize]
        var positions: [CGPoint]
        var totalSize: CGSize
    }
    
    func makeCache(subviews: Subviews) -> Cache {
        // 初始化缓存
        return Cache(
            sizes: [],
            positions: [],
            totalSize: .zero
        )
    }
    
    func updateCache(_ cache: inout Cache, subviews: Subviews) {
        // 只有当子视图变化时才重新计算
        let sizes = subviews.map { $0.sizeThatFits(.unspecified) }
        
        // 计算布局（简化示例）
        var positions: [CGPoint] = []
        var x: CGFloat = 0
        var y: CGFloat = 0
        var maxHeight: CGFloat = 0
        var totalWidth: CGFloat = 0
        
        for size in sizes {
            if x + size.width > 300 { // 假设最大宽度300
                x = 0
                y += maxHeight + spacing
                maxHeight = 0
            }
            
            positions.append(CGPoint(x: x, y: y))
            x += size.width + spacing
            maxHeight = max(maxHeight, size.height)
            totalWidth = max(totalWidth, x)
        }
        
        let totalHeight = y + maxHeight
        
        // 更新缓存
        cache.sizes = sizes
        cache.positions = positions
        cache.totalSize = CGSize(width: totalWidth, height: totalHeight)
    }
    
    func sizeThatFits(
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout Cache
    ) -> CGSize {
        // 直接使用缓存结果
        return cache.totalSize
    }
    
    func placeSubviews(
        in bounds: CGRect,
        proposal: ProposedViewSize,
        subviews: Subviews,
        cache: inout Cache
    ) {
        // 使用缓存的位置信息
        for (index, subview) in subviews.enumerated() {
            if index < cache.positions.count {
                let position = cache.positions[index]
                subview.place(
                    at: CGPoint(
                        x: bounds.minX + position.x,
                        y: bounds.minY + position.y
                    ),
                    anchor: .topLeading,
                    proposal: .unspecified
                )
            }
        }
    }
}
