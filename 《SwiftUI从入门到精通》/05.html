SwiftUI 数据流与绑定

理解单向数据流，掌握 @Published、ObservableObject 以及视图与数据的绑定

一、核心概念：单向数据流

在 SwiftUI 中，单向数据流是构建可预测、可维护应用的核心设计模式。数据从单一可信源（Source of Truth）流向视图，视图的交互产生意图（Intent），意图反过来更新数据源，从而形成一个清晰的循环。

SwiftUI 数据流架构图

图示：数据从模型流向视图，用户交互产生意图并更新模型，形成单向闭环。

单向数据流的优势

  • 可预测性：数据流向单一，易于理解和调试。
  • 可测试性：业务逻辑与视图分离，便于单元测试。
  • 可维护性：状态变化集中管理，减少副作用。
  • 声明式UI：视图是状态的函数，状态变，视图自动更新。

二、关键属性包装器与协议

SwiftUI 通过一系列属性包装器（Property Wrapper）和协议来实现响应式数据流。

@State

用途：管理视图内部的私有状态。

范围：当前视图及其子视图。

特点：值类型，简单状态管理。

struct CounterView: View {
    @State private var count: Int = 0

    var body: some View {
        VStack {
            Text("计数: \(count)")
            Button("增加") {
                count += 1
            }
        }
    }
}

@ObservedObject

用途：引用外部遵循 ObservableObject 协议的可观察对象。

范围：可跨视图共享。

特点：引用类型，用于复杂状态管理。

class UserSettings: ObservableObject {
    @Published var username = "小明"
}

struct SettingsView: View {
    @ObservedObject var settings: UserSettings

    var body: some View {
        Text("用户: \(settings.username)")
    }
}

@StateObject

用途：创建并持有可观察对象的生命周期。

范围：当前视图创建并拥有。

特点：确保对象在视图更新时不被重新创建。

struct ParentView: View {
    @StateObject private var timerData = TimerData() // 由 ParentView 创建并拥有

    var body: some View {
        ChildView(timerData: timerData)
    }
}

@Published 与 ObservableObject 详解

@Published 是 ObservableObject 协议中的核心属性包装器。当标记为 @Published 的属性发生变化时，它会通知所有观察者（视图），从而触发视图更新。

import Combine
import SwiftUI

// 1. 遵循 ObservableObject 协议
class BookViewModel: ObservableObject {
    // 2. 使用 @Published 包装需要监听的属性
    @Published var title: String = "《SwiftUI入门》"
    @Published var isFavorite: Bool = false
    @Published var pageCount: Int = 300

    func toggleFavorite() {
        isFavorite.toggle() // 3. 修改 @Published 属性会自动发布变化
        objectWillChange.send() // 手动触发通知（可选，@Published 已自动处理）
    }
}

三、视图与数据的绑定

绑定（Binding）在视图和数据源之间建立双向连接，允许视图修改数据，同时数据变化也能更新视图。

绑定方式 语法 适用场景 说明
$ 前缀绑定 $propertyName 将 @State, @ObservedObject 等属性绑定到子视图控件 最常用、最简洁的绑定方式
Binding 常量 .constant(value) 提供只读绑定，用于预览或测试 绑定的值不可改变
自定义 Binding Binding(get:, set:) 需要自定义 getter 和 setter 逻辑时 提供最大的灵活性 
struct BindingDemoView: View {
    @State private var text: String = "Hello"
    @State private var isOn: Bool = false
    @State private var sliderValue: Double = 0.5

    // 自定义绑定示例
    private var reversedTextBinding: Binding<String> {
        Binding(
            get: { String(text.reversed()) },
            set: { newValue in
                text = String(newValue.reversed())
            }
        )
    }

    var body: some View {
        VStack(spacing: 20) {
            // 1. 使用 $ 前缀进行双向绑定
            TextField("输入文本", text: $text)
                .textFieldStyle(.roundedBorder)
                .padding()

            Text("你输入了: \(text)")

            // 2. 绑定到 Toggle
            Toggle("开关状态", isOn: $isOn)
            Text(isOn ? "开关已打开" : "开关已关闭")

            // 3. 绑定到 Slider
            Slider(value: $sliderValue, in: 0...1)
            Text("滑块值: \(sliderValue, specifier: "%.2f")")

            // 4. 使用自定义绑定
            TextField("反向文本", text: reversedTextBinding)
                .textFieldStyle(.roundedBorder)
        }
        .padding()
    }
}

四、实战：构建一个任务管理器

综合运用所学知识，创建一个简单的任务管理应用。

import SwiftUI

// MARK: - 数据模型
struct TaskItem: Identifiable {
    let id = UUID()
    var title: String
    var isCompleted: Bool = false
}

// MARK: - 视图模型 (ObservableObject)
class TaskViewModel: ObservableObject {
    @Published var tasks: [TaskItem] = [
        TaskItem(title: "学习 SwiftUI 数据流", isCompleted: true),
        TaskItem(title: "完成项目练习"),
        TaskItem(title: "阅读官方文档")
    ]
    @Published var newTaskTitle = ""

    func addTask() {
        let trimmedTitle = newTaskTitle.trimmingCharacters(in: .whitespaces)
        guard !trimmedTitle.isEmpty else { return }
        let newTask = TaskItem(title: trimmedTitle)
        tasks.append(newTask)
        newTaskTitle = ""
    }

    func toggleTaskCompletion(task: TaskItem) {
        if let index = tasks.firstIndex(where: { $0.id == task.id }) {
            tasks[index].isCompleted.toggle()
        }
    }

    func deleteTask(at offsets: IndexSet) {
        tasks.remove(atOffsets: offsets)
    }
}

// MARK: - 主视图
struct TaskManagerView: View {
    @StateObject private var viewModel = TaskViewModel()

    var body: some View {
        NavigationView {
            VStack {
                // 添加新任务区域
                HStack {
                    TextField("输入新任务...", text: $viewModel.newTaskTitle)
                        .textFieldStyle(RoundedBorderTextFieldStyle())
                        .onSubmit {
                            viewModel.addTask()
                        }

                    Button(action: viewModel.addTask) {
                        Image(systemName: "plus.circle.fill")
                            .font(.title2)
                            .foregroundColor(.green)
                    }
                    .disabled(viewModel.newTaskTitle.trimmingCharacters(in: .whitespaces).isEmpty)
                }
                .padding()

                // 任务列表
                List {
                    ForEach(viewModel.tasks) { task in
                        TaskRowView(task: task)
                            .onTapGesture {
                                viewModel.toggleTaskCompletion(task: task)
                            }
                    }
                    .onDelete(perform: viewModel.deleteTask)
                }
                .listStyle(.insetGrouped)

                // 统计信息
                HStack {
                    Text("总任务: \(viewModel.tasks.count)")
                    Spacer()
                    Text("已完成: \(viewModel.tasks.filter { $0.isCompleted }.count)")
                }
                .padding()
                .background(Color.blue.opacity(0.1))
                .cornerRadius(10)
                .padding(.horizontal)
            }
            .navigationTitle("任务管理器")
            .toolbar {
                EditButton()
            }
        }
    }
}

// MARK: - 任务行子视图
struct TaskRowView: View {
    let task: TaskItem

    var body: some View {
        HStack {
            Image(systemName: task.isCompleted ? "checkmark.circle.fill" : "circle")
                .foregroundColor(task.isCompleted ? .green : .gray)
            Text(task.title)
                .strikethrough(task.isCompleted, color: .gray)
                .foregroundColor(task.isCompleted ? .gray : .primary)
            Spacer()
        }
        .padding(.vertical, 4)
    }
}

五、最佳实践与常见陷阱

最佳实践

  1. 单一数据源：每个数据片段应有且只有一个可信源。
  2. 合理选择属性包装器：
    • 简单视图状态 → @State
    • 共享数据模型 → @ObservedObject 或 @StateObject
    • 从父视图传递的绑定 → @Binding
  3. 视图模型轻量化：视图模型应专注于数据管理和业务逻辑，避免包含视图代码。
  4. 避免循环引用：在使用 @ObservedObject 时注意避免强引用循环。

⚠️ 常见陷阱

  • 错误使用 @StateObject 和 @ObservedObject：在创建实例的视图中使用 @StateObject，在接收实例的视图中使用 @ObservedObject。
  • 在视图体内修改 @Published 属性：应在视图模型的方法中修改，或在 .onAppear、按钮动作等回调中修改。
  • 过度使用绑定：不是所有控件都需要双向绑定，只读数据使用普通属性即可。
  • 忽略主线程规则：更新 UI 必须在主线程进行，@Published 属性应确保在主线程修改。
