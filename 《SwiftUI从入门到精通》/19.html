第19课：本地数据持久化 - 使用@AppStorage、UserDefaults、Core Data与SwiftUI集成

课程简介

在移动应用开发中，数据持久化是至关重要的功能。它允许应用将用户数据、设置和状态保存在设备的本地存储中，即使应用关闭或设备重启，数据也不会丢失。本节课将深入讲解SwiftUI中四种主流的本地数据持久化方案：@AppStorage、UserDefaults、Core Data以及它们与SwiftUI的无缝集成方式。

学习目标：掌握不同场景下数据存储方案的选择与实现，并能在SwiftUI应用中熟练运用。

一、@AppStorage：轻量级状态持久化

@AppStorage是SwiftUI 2.0引入的属性包装器，它基于UserDefaults，专门用于存储简单的用户偏好设置，并自动同步到视图的更新。

特性与用法

  • 声明式语法：与@State类似，使用简单。
  • 自动持久化：值的变化会自动保存到UserDefaults。
  • 适合场景：用户设置、开关状态、简单数值等。
import SwiftUI

struct SettingsView: View {
    @AppStorage("isDarkMode") private var isDarkMode = false
    @AppStorage("username") private var username: String = "Guest"
    @AppStorage("score") private var score: Int = 0

    var body: some View {
        VStack(spacing: 20) {
            Toggle("深色模式", isOn: $isDarkMode)
                .padding()
            TextField("用户名", text: $username)
                .textFieldStyle(RoundedBorderTextFieldStyle())
                .padding()
            Stepper("分数: \(score)", value: $score)
            Text("当前用户: \(username)")
        }
        .padding()
    }
}

注意：@AppStorage的键名是字符串，建议使用常量定义以避免拼写错误。

二、UserDefaults：标准偏好设置存储

UserDefaults是Foundation框架提供的接口，用于存储键值对数据。它比@AppStorage更底层，功能也更灵活。

核心方法

方法描述示例
set(_:forKey:)存储值UserDefaults.standard.set("Alice", forKey: "user")
object(forKey:)获取任意对象let name = UserDefaults.standard.object(forKey: "user")
string(forKey:)获取字符串let name = UserDefaults.standard.string(forKey: "user")
integer(forKey:)获取整数let age = UserDefaults.standard.integer(forKey: "age")
removeObject(forKey:)删除值UserDefaults.standard.removeObject(forKey: "user")

在SwiftUI中的集成示例

import SwiftUI

class UserSettings: ObservableObject {
    @Published var volume: Double {
        didSet {
            UserDefaults.standard.set(volume, forKey: "audioVolume")
        }
    }

    init() {
        self.volume = UserDefaults.standard.double(forKey: "audioVolume")
        if self.volume == 0 {
            self.volume = 0.5 // 默认值
        }
    }
}

struct AudioView: View {
    @StateObject private var settings = UserSettings()

    var body: some View {
        VStack {
            Slider(value: $settings.volume, in: 0...1)
            Text("音量: \(settings.volume, specifier: "%.2f")")
        }
        .padding()
    }
}

三、Core Data：强大的对象图管理

Core Data是Apple提供的对象图管理和持久化框架，适合存储结构化、关系型的复杂数据。

Core Data 与 SwiftUI 集成架构

关键步骤

  1. 创建数据模型：在Xcode中添加Core Data模型文件，定义实体（Entity）和属性。
  2. 设置PersistenceController：创建管理Core Data栈的单例。
  3. 使用@FetchRequest：在SwiftUI视图中直接获取数据。
  4. 使用@Environment(\.managedObjectContext)：获取上下文以进行增删改操作。
import SwiftUI
import CoreData

// 1. 定义实体 `TaskItem` (在.xcdatamodeld文件中)
// 属性: id (UUID), title (String), isCompleted (Bool), createdAt (Date)

struct TaskListView: View {
    // 2. 获取数据
    @FetchRequest(
        entity: TaskItem.entity(),
        sortDescriptors: [NSSortDescriptor(keyPath: \TaskItem.createdAt, ascending: false)]
    ) var tasks: FetchedResults

    // 3. 获取托管对象上下文
    @Environment(\.managedObjectContext) private var viewContext

    @State private var newTaskTitle = ""

    var body: some View {
        NavigationView {
            VStack {
                HStack {
                    TextField("新任务", text: $newTaskTitle)
                        .textFieldStyle(RoundedBorderTextFieldStyle())
                    Button("添加") {
                        addTask()
                    }
                    .padding(.horizontal)
                    .disabled(newTaskTitle.isEmpty)
                }
                .padding()

                List {
                    ForEach(tasks) { task in
                        HStack {
                            Image(systemName: task.isCompleted ? "checkmark.circle.fill" : "circle")
                                .foregroundColor(.green)
                                .onTapGesture {
                                    toggleTask(task)
                                }
                            Text(task.title ?? "未命名")
                            Spacer()
                        }
                    }
                    .onDelete(perform: deleteTasks)
                }
            }
            .navigationTitle("任务列表")
        }
    }

    private func addTask() {
        withAnimation {
            let newTask = TaskItem(context: viewContext)
            newTask.id = UUID()
            newTask.title = newTaskTitle
            newTask.createdAt = Date()
            newTask.isCompleted = false
            saveContext()
            newTaskTitle = ""
        }
    }

    private func toggleTask(_ task: TaskItem) {
        task.isCompleted.toggle()
        saveContext()
    }

    private func deleteTasks(offsets: IndexSet) {
        withAnimation {
            offsets.map { tasks[$0] }.forEach(viewContext.delete)
            saveContext()
        }
    }

    private func saveContext() {
        do {
            try viewContext.save()
        } catch {
            print("保存失败: \(error)")
        }
    }
}

四、方案对比与选择指南

@AppStorage

  • 数据类型：简单类型（String, Int, Bool等）
  • 存储量：极小
  • 复杂度：极低
  • 适用场景：用户设置、开关状态

UserDefaults

  • 数据类型：属性列表支持的类型
  • 存储量：小（< 几百KB）
  • 复杂度：低
  • 适用场景：应用配置、简单数据

Core Data

  • 数据类型：复杂对象图、关系型数据
  • 存储量：大（可到GB级）
  • 复杂度：高
  • 适用场景：笔记、通讯录、库存管理等

五、实战建议与总结

选择策略

  • 存储用户偏好设置（如主题、音效开关） → 优先使用@AppStorage。
  • 存储少量结构化数据（如用户档案、游戏最高分） → 使用UserDefaults或@AppStorage。
  • 构建数据密集型应用（如待办事项、日记、产品目录） → 必须使用Core Data。
  • 考虑未来数据迁移和版本升级时，Core Data的模型版本管理功能非常有用。

核心要点：SwiftUI通过@AppStorage、@FetchRequest等属性包装器，将数据持久化与声明式UI深度绑定，使得状态管理更加直观和高效。理解每种工具的特性和适用场景，是构建健壮iOS/macOS应用的关键。
