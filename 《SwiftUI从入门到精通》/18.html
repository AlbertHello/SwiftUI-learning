第18章：网络请求与数据

结合URLSession、Combine在SwiftUI中进行网络数据获取与展示

本章概述

在现代移动应用开发中，网络数据获取是核心功能之一。SwiftUI 作为声明式UI框架，与 Apple 原生的 URLSession 和响应式编程框架 Combine 相结合，能够构建出高效、可维护的网络数据流。本章将深入讲解如何利用这三者构建稳健的数据层，并在 SwiftUI 视图中优雅地展示数据。

学习目标：掌握在 SwiftUI 应用中发起网络请求、处理响应、管理状态以及展示数据的最佳实践。

核心技术栈

1. URLSession

Apple 提供的用于网络数据传输的任务类。它是进行 HTTP/HTTPS 请求的基础。

2. Combine

Apple 的响应式编程框架，用于处理随时间变化的值流（事件流）。

3. SwiftUI

声明式UI框架，通过状态驱动视图更新，与 Combine 的发布者天然契合。

架构流程图

该架构遵循 MVVM（Model-View-ViewModel） 模式，利用 Combine 的发布者将网络数据流绑定到 SwiftUI 视图的状态上，实现单向数据流，使代码更清晰、更易测试。

关键步骤与代码实现

1. 定义数据模型 (Model)

首先，根据 API 返回的 JSON 结构定义对应的 Swift Codable 模型。

import Foundation

// 示例：从 JSONPlaceholder 获取帖子数据
struct Post: Codable, Identifiable {
    let id: Int
    let userId: Int
    let title: String
    let body: String
}

2. 创建网络服务层 (Network Service)

使用 URLSession 和 Combine 封装可复用的网络请求方法。

import Foundation
import Combine

class NetworkService {
    static let shared = NetworkService()
    private let baseURL = "https://jsonplaceholder.typicode.com"
    private var cancellables = Set<AnyCancellable>()

    private init() {}

    // 泛型方法，用于获取并解码 JSON 数据
    func fetch<T: Decodable>(_ endpoint: String) -> AnyPublisher<T, Error> {
        let url = URL(string: baseURL + endpoint)!
        return URLSession.shared.dataTaskPublisher(for: url)
            .map(\.data) // 提取数据
            .decode(type: T.self, decoder: JSONDecoder()) // 解码为模型
            .receive(on: DispatchQueue.main) // 在主线程接收
            .eraseToAnyPublisher() // 类型擦除，便于返回
    }

    // 示例：获取帖子列表
    func fetchPosts() -> AnyPublisher<[Post], Error> {
        return fetch("/posts")
    }
}

3. 构建视图模型 (ViewModel)

视图模型负责管理状态、调用网络服务，并通过 @Published 属性通知视图更新。

import Foundation
import Combine

class PostViewModel: ObservableObject {
    @Published var posts: [Post] = []
    @Published var isLoading = false
    @Published var errorMessage: String?

    private let networkService = NetworkService.shared
    private var cancellables = Set<AnyCancellable>()

    func loadPosts() {
        isLoading = true
        errorMessage = nil

        networkService.fetchPosts()
            .sink(receiveCompletion: { [weak self] completion in
                self?.isLoading = false
                if case .failure(let error) = completion {
                    self?.errorMessage = error.localizedDescription
                }
            }, receiveValue: { [weak self] fetchedPosts in
                self?.posts = fetchedPosts
            })
            .store(in: &cancellables) // 存储订阅，管理生命周期
    }
}

4. 构建 SwiftUI 视图 (View)

视图订阅视图模型中的 @Published 属性，并根据状态展示不同的UI。

import SwiftUI

struct PostListView: View {
    @StateObject private var viewModel = PostViewModel()

    var body: some View {
        NavigationView {
            VStack {
                if viewModel.isLoading {
                    ProgressView("加载中...")
                        .scaleEffect(1.5)
                        .padding()
                } else if let error = viewModel.errorMessage {
                    VStack {
                        Image(systemName: "exclamationmark.triangle")
                            .font(.largeTitle)
                            .foregroundColor(.orange)
                        Text("出错啦")
                            .font(.headline)
                        Text(error)
                            .font(.caption)
                            .foregroundColor(.gray)
                            .multilineTextAlignment(.center)
                        Button("重试") {
                            viewModel.loadPosts()
                        }
                        .padding()
                        .background(Color.blue)
                        .foregroundColor(.white)
                        .cornerRadius(8)
                    }
                    .padding()
                } else {
                    List(viewModel.posts) { post in
                        VStack(alignment: .leading, spacing: 8) {
                            Text(post.title)
                                .font(.headline)
                                .foregroundColor(.primary)
                            Text(post.body)
                                .font(.body)
                                .foregroundColor(.secondary)
                                .lineLimit(2)
                        }
                        .padding(.vertical, 5)
                    }
                    .listStyle(PlainListStyle())
                }
            }
            .navigationTitle("帖子列表")
            .toolbar {
                ToolbarItem(placement: .navigationBarTrailing) {
                    Button(action: {
                        viewModel.loadPosts()
                    }) {
                        Image(systemName: "arrow.clockwise")
                    }
                    .disabled(viewModel.isLoading)
                }
            }
            .onAppear {
                if viewModel.posts.isEmpty {
                    viewModel.loadPosts()
                }
            }
        }
    }
}

Combine 操作符速查表

操作符 功能描述 使用场景
map 转换发布者输出的值。 从 DataTaskPublisher.Output 中提取 data。
decode 将数据解码为指定类型的模型。 将 JSON Data 解码为 Post 数组。
catch 捕获错误并返回一个新的发布者。 网络错误时返回一个空数组或默认值。
receive(on:) 指定接收结果的调度队列。 确保 UI 更新在主线程 DispatchQueue.main。
sink 订阅发布者，接收完成事件和值。 在视图模型中接收网络数据或错误。
store(in:) 存储订阅，管理其生命周期。 防止订阅被提前释放，通常存储在 Set<AnyCancellable> 中。

最佳实践与注意事项

  • 错误处理：务必使用 catch 或 sink 的 receiveCompletion 处理网络错误，给用户友好提示。
  • 内存管理：使用 store(in: &cancellables) 妥善管理 Combine 订阅，避免内存泄漏。
  • 线程安全：使用 receive(on:) 确保 UI 更新发生在主线程。
  • 状态管理：在视图模型中清晰定义加载、成功、失败等状态，驱动视图正确显示。
  • 可测试性：通过依赖注入（如将 NetworkService 作为协议注入视图模型）可以方便地编写单元测试。
  • 用户体验：在加载时显示进度指示器，提供下拉刷新或重试按钮。

本章总结

通过本章学习，我们掌握了在 SwiftUI 应用中集成网络功能的完整方案：

  1. 使用 URLSession.dataTaskPublisher 发起网络请求。
  2. 利用 Combine 框架以声明式和响应式的方式处理异步数据流和错误。
  3. 遵循 MVVM 模式，构建清晰的数据流（视图 → 视图模型 → 服务层 → 网络）。
  4. 在 SwiftUI 视图中，通过 @StateObject 和 @Published 实现数据与UI的自动绑定与更新。

这套组合拳使得网络请求代码更简洁、更健壮，并且与 SwiftUI 的声明式特性完美融合，是开发现代 iOS/macOS 应用的必备技能。
