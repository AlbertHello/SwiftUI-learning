SwiftUI动画基础

第八讲：隐式动画、显式动画、过渡与动画曲线

📚 课程概述

动画是提升用户体验的核心。SwiftUI 提供了声明式、强大的动画 API，让开发者能够轻松创建流畅的界面交互。本讲将深入探讨 SwiftUI 动画的四大基石：隐式动画、显式动画、过渡 与 动画曲线。

🎯 一、隐式动画 (.animation)

隐式动画 是 SwiftUI 中最简单的动画添加方式。通过为视图修饰符添加 .animation() 修饰符，该视图所有可动画的属性变化都会以动画形式呈现。

核心特性

  • 声明式：直接附加在视图上，声明动画效果。
  • 作用范围：仅作用于被修饰的视图及其子视图的特定属性变化。
  • 自动触发：当依赖的状态（@State）改变时，动画自动执行。

代码示例

import SwiftUI

struct ImplicitAnimationView: View {
    @State private var isExpanded: Bool = false

    var body: some View {
        VStack {
            // 点击时，圆形的大小和颜色会以动画方式改变
            Circle()
                .fill(isExpanded ? Color.orange : Color.green)
                .frame(width: isExpanded ? 150 : 80,
                       height: isExpanded ? 150 : 80)
                .animation(.easeInOut(duration: 0.8), value: isExpanded) // 隐式动画

            Button("切换状态") {
                isExpanded.toggle() // 状态改变触发动画
            }
            .padding()
            .background(Color.blue)
            .foregroundColor(.white)
            .cornerRadius(10)
        }
    }
}
💡 提示： 在 SwiftUI 3.0+ 中，推荐使用 .animation(.easeInOut, value: isExpanded) 这种指定依赖值的方式，性能更优，动画更精确。

🚀 二、显式动画 (withAnimation)

显式动画 通过 withAnimation { ... } 闭包包裹状态改变代码，明确指定一段代码执行时应伴随动画。它提供了更精细的控制能力。

核心特性

  • 命令式触发：在需要的地方主动调用。
  • 作用范围：闭包内所有因状态改变而发生的视图变化都会产生动画。
  • 灵活控制：可以为不同的状态变化指定不同的动画参数。

代码示例

struct ExplicitAnimationView: View {
    @State private var offsetX: CGFloat = 0
    @State private var rotation: Double = 0

    var body: some View {
        VStack(spacing: 30) {
            Rectangle()
                .fill(Color.purple)
                .frame(width: 100, height: 100)
                .offset(x: offsetX)
                .rotationEffect(.degrees(rotation))

            HStack {
                Button("向右移动") {
                    // 使用显式动画，指定弹簧效果
                    withAnimation(.spring(response: 0.6, dampingFraction: 0.5)) {
                        offsetX += 50
                    }
                }
                .padding()
                .background(Color.green)
                .foregroundColor(.white)
                .cornerRadius(8)

                Button("旋转") {
                    // 使用另一个显式动画，指定线性动画
                    withAnimation(.linear(duration: 1.0)) {
                        rotation += 180
                    }
                }
                .padding()
                .background(Color.blue)
                .foregroundColor(.white)
                .cornerRadius(8)
            }
        }
    }
}

🔄 三、过渡 (Transition)

过渡 定义了视图如何出现和消失。它通常与条件语句（如 if）结合使用，控制视图的插入和移除动画。

常用过渡效果

.opacity

淡入淡出

.scale

缩放效果

.slide

滑入滑出

.move(edge:)

从某边移入

代码示例

struct TransitionView: View {
    @State private var showDetails = false

    var body: some View {
        VStack {
            Button(showDetails ? "隐藏详情" : "显示详情") {
                withAnimation(.easeInOut(duration: 0.5)) {
                    showDetails.toggle()
                }
            }
            .padding()
            .background(Color.orange)
            .foregroundColor(.white)
            .cornerRadius(10)

            if showDetails {
                Text("🎉 这里是详细的说明内容！")
                    .padding()
                    .frame(maxWidth: .infinity)
                    .background(Color.yellow)
                    .cornerRadius(10)
                    .transition(.asymmetric( // 组合过渡：进入和退出使用不同效果
                        insertion: .scale.combined(with: .opacity),
                        removal: .slide.combined(with: .opacity)
                    ))
            }

            Spacer()
        }
        .padding()
    }
}

📈 四、动画曲线 (Animation Curve)

动画曲线（或时间函数）决定了动画过程中速度如何变化，是影响动画“感觉”的关键因素。SwiftUI 提供了丰富的内置曲线。

主要曲线类型

曲线类型 描述 适用场景
.linear 匀速运动 机械、匀速移动（如进度条）
.easeIn 由慢到快，加速结束 物体从静止开始加速（如自由落体开始）
.easeOut 由快到慢，减速结束 物体逐渐停止（如刹车）
.easeInOut 慢-快-慢，对称变化 最自然、最常用的通用动画
.spring() 弹簧物理模拟 富有弹性的、生动的交互

弹簧动画示例

// 自定义弹簧动画
withAnimation(.spring(
    response: 0.6,      // 定义弹簧的刚度（响应速度）
    dampingFraction: 0.5, // 阻尼系数（0.0-1.0），越小弹跳越多
    blendDuration: 0.25   // 与其他动画混合的时间
)) {
    // 状态改变
    scale = 2.0
}

✅ 总结与最佳实践

  1. 选择合适的动画类型：
    • 简单属性变化 → 使用 隐式动画。
    • 复杂逻辑、多个状态联动 → 使用 显式动画。
    • 视图的插入与移除 → 使用 过渡。
  2. 选择合适的动画曲线：
    • 追求自然 → .easeInOut。
    • 追求生动、趣味 → .spring()。
    • 保持一致性，避免一个界面中使用过多不同的曲线。
  3. 性能优化：
    • 为隐式动画指定具体的依赖值（value参数）。
    • 避免在每一帧都触发状态更新的动画中执行繁重操作。
    • 使用 .animation(nil) 在视图层级中局部禁用动画。
