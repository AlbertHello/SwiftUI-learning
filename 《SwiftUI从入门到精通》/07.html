SwiftUI 从入门到精通

第7章：表单与用户输入
Form、TextField、SecureField、TextEditor、Toggle、Picker、Slider、Stepper

📝 章节概述

在移动应用开发中，表单是与用户进行交互、收集信息的关键组件。SwiftUI 提供了一系列强大、声明式的表单控件，让开发者能够轻松构建美观、响应式的用户输入界面。本章将深入讲解这些核心控件，并通过实例展示如何将它们组合起来创建功能完整的表单。

所有控件都遵循 SwiftUI 的声明式语法和状态驱动原则，通过 @State、@Binding 等属性包装器管理数据流。

数据流：用户操作 → 控件 → @State 状态 → 视图更新

📋 核心控件详解

下面表格列出了本章要讲解的所有核心表单控件及其主要用途：

控件名称 图标 主要用途 关键属性/修饰符
Form 📑 表单容器，自动适配平台样式，对控件进行分组和布局。 .formStyle(), Section
TextField ✏️ 单行文本输入框，用于输入用户名、搜索词等。 text:, placeholder:, .textFieldStyle()
SecureField 🔒 安全文本输入框，用于输入密码等敏感信息，内容隐藏。 同 TextField，但内容掩码显示。
TextEditor 📄 多行文本编辑区域，用于输入长文本、备注等。 text:, .frame(minHeight:)
Toggle 🔘 开关控件，用于布尔值选择（开/关）。 isOn:, .toggleStyle()
Picker 📌 选择器，用于从一组选项中选择一个值。 selection:, .pickerStyle()
Slider 🎚️ 滑块，用于在一个范围内选择连续数值。 value:in:, step:
Stepper 🔢 步进器，用于以固定步长增加或减少数值。 value:in:step:, onIncrement/decrement:

🧩 控件使用示例与代码

让我们通过一个综合的注册表单示例，来学习这些控件的具体用法。我们将创建一个包含多种输入控件的界面。

import SwiftUI

struct RegistrationFormView: View {
    // 1. 使用 @State 管理表单数据
    @State private var username: String = ""
    @State private var password: String = ""
    @State private var bio: String = "请输入个人简介..."
    @State private var receiveNotifications: Bool = true
    @State private var selectedColorIndex: Int = 0
    @State private var brightness: Double = 0.5
    @State private var age: Int = 18

    let colorOptions = ["红色", "蓝色", "绿色", "黄色"]

    var body: some View {
        // 2. Form 作为容器
        Form {
            Section(header: Text("账户信息").font(.headline)) {
                // 3. TextField 输入用户名
                TextField("请输入用户名", text: $username)
                    .textFieldStyle(RoundedBorderTextFieldStyle())
                    .autocapitalization(.none)

                // 4. SecureField 输入密码
                SecureField("请输入密码", text: $password)
                    .textFieldStyle(RoundedBorderTextFieldStyle())

                // 5. Toggle 开关
                Toggle("接收通知", isOn: $receiveNotifications)
                    .toggleStyle(SwitchToggleStyle(tint: .blue))
            }

            Section(header: Text("个人资料").font(.headline)) {
                // 6. Picker 选择颜色
                Picker("最喜欢的颜色", selection: $selectedColorIndex) {
                    ForEach(0 ..< colorOptions.count, id: \.self) { index in
                        Text(colorOptions[index]).tag(index)
                    }
                }
                .pickerStyle(MenuPickerStyle())

                // 7. Slider 调整亮度
                HStack {
                    Text("界面亮度")
                    Slider(value: $brightness, in: 0...1, step: 0.1)
                    Text("\(brightness, specifier: "%.1f")")
                }

                // 8. Stepper 选择年龄
                Stepper(value: $age, in: 0...120, step: 1) {
                    Text("年龄: \(age)")
                }

                // 9. TextEditor 输入简介
                Text("个人简介")
                    .font(.headline)
                TextEditor(text: $bio)
                    .frame(minHeight: 100)
                    .border(Color.gray.opacity(0.3), width: 1)
                    .cornerRadius(5)
            }

            Section {
                Button(action: submitForm) {
                    HStack {
                        Image(systemName: "paperplane.fill")
                        Text("提交注册")
                            .fontWeight(.bold)
                    }
                    .frame(maxWidth: .infinity)
                }
                .buttonStyle(.borderedProminent)
                .controlSize(.large)
                .disabled(username.isEmpty || password.isEmpty) // 简单验证
            }
        }
        .navigationTitle("用户注册")
        .padding()
    }

    func submitForm() {
        print("提交数据：")
        print("用户名: \(username)")
        print("密码长度: \(password.count)")
        print("颜色: \(colorOptions[selectedColorIndex])")
        print("年龄: \(age)")
        // 实际开发中，这里会发送网络请求
    }
}

    }

💡 关键知识点：
  • @State：用于声明视图内部的可变状态，当状态改变时，视图会自动更新。
  • $（美元符号）：前缀用于创建与状态变量的双向绑定（Binding），将控件与数据源连接起来。
  • Form 和 Section：用于逻辑分组，提升表单的可读性和可访问性。
  • 每个控件都有丰富的修饰符（如 .pickerStyle()）用于自定义外观和行为。

🎨 控件视觉展示与特性

📑 Form & Section

作用：表单容器与分组。

特性：自动适配 iOS/macOS 平台样式，提供清晰的视觉分隔。

✏️ TextField

作用：单行文本输入。

特性：支持占位符、键盘类型、自动校正等。

🔒 SecureField

作用：安全密码输入。

特性：输入内容显示为圆点，保护隐私。

📄 TextEditor

作用：多行文本编辑。

特性：可滚动，适合长文本。

🔘 Toggle

作用：布尔开关。

特性：多种样式（Switch, Button, Checkbox）。

📌 Picker

作用：从列表中选择。

特性：支持 Wheel, Segmented, Menu 等样式。

🎚️ Slider

作用：连续值选择。

特性：可定义范围、步长、最小/最大标签。

🔢 Stepper

作用：离散值步进。

特性：可自定义增减操作和范围。

✅ 最佳实践与总结

  1. 状态管理是核心：始终使用 @State, @Binding, @ObservedObject 等属性包装器来管理表单数据，确保 UI 与数据同步。
  2. 合理分组：使用 Form 和 Section 将相关控件分组，使表单结构清晰，提升用户体验。
  3. 即时验证：利用 .disabled() 修饰符或条件语句，在用户输入时提供即时反馈（如提交按钮的禁用状态）。
  4. 平台适配：注意不同控件在 iOS、macOS 上的默认样式差异，使用 .pickerStyle() 等修饰符进行适当调整。
  5. 辅助功能：为控件添加 .accessibilityLabel() 等修饰符，确保应用对屏幕阅读器等辅助工具友好。

通过本章的学习，你已经掌握了 SwiftUI 中构建交互式表单所需的所有基本控件。将它们组合起来，你可以创建出从简单的设置页面到复杂的数据录入界面等各种功能。
